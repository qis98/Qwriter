# 数据位置与隐私

文章、图片、任务记录和公众号加密配置默认位于 `安装目录\Qwriter\workspace`，可在设置中迁移。旧用户升级沿用原目录。安装位置不可写时会使用当前Windows用户的数据目录，并在设置中提示。

WorkBuddy登录凭据、本机网关状态和应用偏好位于Windows用户配置目录下的 `wechat-article-studio`。此名称用于兼容既有版本。模型登录状态不随文章备份导出。

AppSecret使用Windows当前用户的系统加密能力保护。微信access_token仅在主进程内存复用，不发送给界面、不写入缓存文件。模型连接通过本机回环网关完成；本机数据保存不意味着模型离线运行，生成所需内容仍发送至相应平台。

安装包只包含程序、运行时、图标与许可文件，不包含作者的登录状态、公众号配置或文章。仓库不提交本地数据、历史验证目录、运行日志或密钥文件。

请保管本机账号、备份与数据目录。不要把整个工作目录、配置JSON、AppSecret或登录令牌发到公开Issue。数据迁移和备份应在任务结束后执行。
