# 第一次使用 Qwriter

## 下载和安装

1. 打开[最新版本页面](https://github.com/qis98/Qwriter/releases/latest)。
2. 在 **Assets** 下载 `Qwriter-Setup-版本号-x64.exe`。不要下载 Source code 作为安装包。
3. 运行安装程序并选择安装目录。当前安装包未配置数字签名，请确认下载来源。
4. 打开Qwriter。普通用户无需安装开发工具或单独部署服务器。

## 登录模型账号

在首次引导或“设置与连接”中登录本人WorkBuddy账号，按页面完成授权。回到软件检查连接状态。生成文章和图片使用该账号的额度；可用模型和额度由上游平台决定。

## 连接微信公众号

1. 打开软件中的微信配置页，用公众号管理员微信扫码登录。
2. 进入“公众号 → 基础信息 → 开发密钥”，选择自己的公众号。
3. 复制开发者ID（AppID）与开发者密码（AppSecret），手动填写到Qwriter。
4. 点击检查连接。如提示IP白名单未配置，复制软件显示的IP，追加到开发者平台的 **API IP白名单**。保留已有IP。
5. 保存微信后台设置后，回Qwriter重新检查。

请保管好AppSecret，不要发到Issue或聊天。重置密钥会影响其他使用同一公众号密钥的程序，请按需操作。公众号需具备相应素材、草稿或发布接口权限；扫码登录开发者页面本身不代表这些权限已经具备。

## 创作、编辑和草稿

输入主题，选择字数、语气和配图后生成。自定义字数留空按300字，允许100至12,000字；长文会分章节生成。

点击“编辑”可修改文字和格式。点击图片后可替换、删除或调整宽度，编辑器内也可以更换封面。工作台“保存修改”先保存本地内容；生成后自动存公众号草稿默认开启，可在设置关闭。

发布中心可同步已有草稿。此处“保存到公众号草稿”会更新所选云端草稿，软件会检查版本并重新读回核对。若提示结果未确认，请重新同步并核对已有草稿，不要盲目重复操作。

## 公开发表、群发与定时

选择草稿、发送方式和时间，核对内容后勾选确认。各项能力取决于公众号接口权限。定时任务由本机执行，必须保持软件开启、电脑唤醒并联网；错过时间不会自动补发。清理任务记录不会删除文章；发布记录归档会保留防重复发送依据。

## 常见问题

- **模型连接失败**：检查本人账号是否授权、额度是否可用，必要时重新登录；非官方适配也可能受上游变更影响。
- **AppSecret不正确**：核对当前公众号和密钥，在软件中更新后重新检查。
- **IP变化**：网络或出口改变后可能需要更新API IP白名单，以软件检查结果为准。
- **没有某项接口权限**：到微信开发者平台检查对应能力；软件不能绕过账号权限。
- **升级后数据在哪里**：升级保留原数据目录，在“设置与连接 → 本地数据”查看或迁移。
- **不知道是否已经保存或发送**：先查询微信结果或核对公众号后台，软件不会对结果不明确的公开提交自动重发。
